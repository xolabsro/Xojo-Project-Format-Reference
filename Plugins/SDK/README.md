# Xojo Plugins SDK — Headers and Glue Code

An unmodified copy of `Includes/` and `GlueCode/` from the Xojo Plugins SDK 2026r1, as shipped with Xojo 2026r3 in
`Extras/PluginsSDK`.

- Compile `GlueCode/PluginMain.cpp` into every plugin and put `Includes/` on the include path.
- macOS plugins with Cocoa views also compile `GlueCode/PluginMainCocoa.mm`.
- Don't edit these files. How to use them: [../README.md](../README.md).
